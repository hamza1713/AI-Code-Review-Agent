# M14–M16 implementation checkpoints

This document records the post-M13 stabilization, security-audit closure, dependency repair, and repository cleanup checkpoints. Hosted CI, attributed release approval, paid model captures, and independent human corpus labels remain separate release gates.

## M14: agentic loop hardening, feature truthfulness & polyglot Tree-Sitter

- **Bounded inspection loop (`crew.py`, `tasks.yaml`):** Kept the `max_tool_calls=4` read-only inspection loop while replacing substring matching with exact normalized tool-name lookup, filtering kwargs against Pydantic `args_schema` or callable signatures, decoupling budget-exhaustion prompting from 1-shot schema repair, hydrating diff snippets in `crew_finding_parser.py`, and preserving `why` + `suggestion_code` in `review_policy.py`. Amended [`docs/PRODUCTION_ARCHITECTURE.md`](PRODUCTION_ARCHITECTURE.md) to document the v3.0 divergence from M9.
- **Honest opt-in stages & flags:** Wired `AdversarialVerifier` behind `REVIEW_ENABLE_ADVERSARIAL_VERIFIER=false`, ticket compliance behind `REVIEW_ENABLE_TICKET_COMPLIANCE=false`, and experimental sandbox test execution behind `REVIEW_ENABLE_EXPERIMENTAL_TESTS=false`. Removed unused `deepeval>=1.5.0` from `pyproject.toml`. Populated `ReviewState.summarized_findings`, verified `canary_verified`, and documented `RAG_ENABLED=false` default.
- **Dynamic ZDR & tenancy honesty (`review_service.py`, `tenancy.py`, `webhook_server.py`):** Replaced invalid `provider_of` usage with `LLMFactory.resolve_provider`; `zero_data_retention` now evaluates `True` only for local `ollama` endpoints. Gateway routes default to single-operator `"default"` tenancy (`REVIEW_MULTI_TENANT=false`) so spoofed `X-Tenant-ID` headers are ignored unless multi-tenant routing is explicitly enabled.
- **Polyglot Tree-Sitter on Python 3.10–3.13 (`pyproject.toml`, `code_graph.py`):** Replaced incompatible `tree-sitter-languages` with `tree-sitter-language-pack>=1.20.0,<1.24.0` + `tree-sitter>=0.23.0` so all 7 non-Python extensions (`.js`, `.jsx`, `.ts`, `.tsx`, `.go`, `.java`, `.rs`) parse cleanly without regex fallback.
- **Frontend consensus honesty (`AIThreatRadar.tsx`, `types/review.ts`):** Guarded consensus displays when adversarial verification is inactive or unavailable instead of fabricating default agreement scores.

## M15: audit remediation (`K1–K17`), SAST diff scan & full `mypy` CI gate

- **AutoRemediator & SAST fixes (`remediator.py`, `tools/sast_scanner.py`):** Resolved audit findings `K1–K12` and `K15` (removed partial-snippet full-file fallback, added pre-commit AST & `SastEngine.scan_diff` verification, reordered deterministic fix templates ahead of prose scraping, fixed multi-var SQLi, literal secret replacement, and non-list `shell=True` guards, mandated `reviewed_head`, removed `apply_code_patch` fallback and `"feature-remediation"` fallback, enforced `is_fork` / `head_repository` fork guards, recorded `PENDING` + `SOURCE_REMEDIATION_APPLIED` lifecycle updates, strict UTF-8 decoding, and `_open_db()` closing connections). Fixed `QuickPatternScanner.scan_diff` multiline scans to ignore diff headers/deleted lines and require overlap with `+`-added spans.
- **Additional audit closures (`K13`, `K14`, `K16`, `K17`):** Verified HTML escaping on fallback highlights in `AnnotatedCodeViewer.tsx` (`K13`), actor attribution in `bot/command_router.py` (`K14`), advisory phrasing in `action.yml` (`K16`), and workspace-bounded `repo_root` validation in `mcp_server.py` (`K17`). See [`docs/AUDIT_REPORT.md`](AUDIT_REPORT.md).
- **Typing & regression gates (`.github/workflows/ci.yml`, `tests/test_m14_m15_regressions.py`):** Widened CI `mypy` gate from `models.py` alone to `uv run mypy --ignore-missing-imports src/code_review_agent`, and added non-skipping Tree-Sitter and M14/M15 regression tests.
